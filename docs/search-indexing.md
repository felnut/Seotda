‘발견됨, 현재 색인 미생성’ 항목은 0건이다. 홈은 이미 크롤링되었으므로 발견 요청이 전달되지 않았다고 볼 근거가 없다. `/rules`와 `/rooms`가 색인된 점도 사이트 전체가 차단된 상황과 다르다. 본사이트의 리디렉션 세 건은 섯다의 색인 미생성과 별개다. 정상 대표 주소로 이동하는지 여부는 운영 응답을 확인해야 한다.

이 내보내기에는 Google이 선택한 표준 URL, 크롤링된 HTML, URL별 세부 제외 이유가 없다. 중복 판단, 콘텐츠 평가, 제재 중 어느 것이 원인이라고 확정할 수 없으며, 디자인 변경이나 색인 요청이 색인을 보장하지 않는다.

## 이번 변경

- 홈에 게임 방식, 인원, 게스트 참가, AI 참가, 가상 칩 설명과 규칙 링크를 제공한다. 내용은 초기 서버 HTML에도 포함된다.
- 17개 장문 가이드 글을 없애고 규칙은 `/rules`, 간단한 시작·베팅 안내는 `/guide`로 정리했다. 관련 내용이 남은 기존 16개 글은 해당 안내 항목으로 308 리디렉션한다.
- 별도 확률 설명을 없앤 `/guide/hand-probability`는 대체 콘텐츠가 없어 404로 처리한다. 존재하지 않는 가이드 주소도 404이며 홈으로 무조건 돌리지 않는다.
- 사이트맵에는 간결한 `/guide`만 남기고 개별 가이드 글 주소를 제거했다. 이미 색인된 `/rules`, `/rooms` 주소를 유지한다.
- Googlebot을 허용하는 기존 robots 설정을 유지한다. `Google-Extended` 차단은 Google 검색 크롤링 차단과 다르다.
- 실제 주소 대신 포트폴리오 URL을 넣었던 Organization의 `address`를 제거했다. 이것이 색인 실패의 원인이라는 의미는 아니다.
- 테마별 외부 폰트를 없앴다. 공유 이미지는 포함된 한국어 글꼴로 생성해 빌드 때 외부 폰트 요청을 하지 않는다.

## 배포 후 확인

1. `https://seotda.felnut.com/` URL 검사에서 **Google이 선택한 표준 URL**, 사용자 선언 표준 URL, 크롤링 허용 여부, 색인 허용 여부를 확인한다. 다른 주소를 표준으로 선택했다면 그 주소와 중복·리디렉션 관계를 먼저 확인한다.
2. 실시간 URL 테스트와 렌더링된 화면에서 홈 설명 및 방 만들기 화면이 보이는지 확인한다. 정상 200, 자기 자신을 가리키는 canonical, `noindex` 부재를 확인한다. 이 저장소의 수정본에서는 로컬 프로덕션 응답으로 검증했다.
3. 갱신된 `https://seotda.felnut.com/sitemap.xml`을 제출하고 홈의 색인 생성을 요청한다. 반복 요청으로 처리 속도가 빨라진다고 가정하지 않는다.
4. `/guide`는 정상 표시되고, 기존 글은 해당 안내 절로 이동하는지 확인한다. 리디렉션 출발 URL 자체가 색인 제외되는 것은 의도한 결과다.
5. 보고서의 마지막 크롤링 날짜가 배포 이후로 갱신되는지 확인한다. 약관·개인정보 페이지까지 모두 색인되는 것을 성공 조건으로 삼지 않는다.

현재 환경에서 운영 도메인 HTTPS 요청은 프록시가 403으로 거부했다. 이 403은 Googlebot이 운영 사이트에서 받은 응답이라는 뜻이 아니다. 로그인된 Search Console에 직접 접근하거나 색인 요청을 제출하지 않았다.
